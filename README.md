🫧 What is Oozy?

Oozy Linux is an Arch-based distribution for people who want Arch without needing to already understand Arch.

Oozy provides a simple starting point while gradually teaching users how Linux works.

The goal isn't to hide Linux.

The goal is to teach it.

«Start as a goo ball. Learn Linux. Evolve.»

Eventually, an Oozy user should know enough to install Arch themselves.

🐧 Built on Arch

Oozy uses Arch as its foundation.

That means users get access to the things that make Arch attractive:

- Rolling releases
- "pacman"
- The Arch ecosystem
- Extensive documentation
- AUR
- Highly customizable systems

Oozy adds a beginner-friendly layer without trying to reinvent Linux underneath it.

🛠️ Development

The project is being built openly.

Oozy will prioritize:

- Upstream compatibility
- Reproducible builds
- Minimal unnecessary modifications
- Clear documentation
- Easy recovery
- Sensible defaults

The intention is to build on top of existing Linux infrastructure, not maintain a gigantic pile of unnecessary forks.
